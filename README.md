# Jerry Meraki Website

This is the first static website for Jerry Meraki Print Enterprise.

It is built with plain HTML, CSS, and JavaScript so it can be hosted for free on Cloudflare Pages, GitHub Pages, or Netlify.

No build tool is required.

## Files

- `index.html` - main website
- `privacy.html` - privacy notice
- `404.html` - not found page
- `styles.css` - visual design
- `script.js` - quote form and icons
- `assets/print-production-hero.png` - local hero image
- `assets/favicon.svg` - website icon

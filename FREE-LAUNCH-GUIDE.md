# Free Launch Guide

The website itself is free to run because it is a static website.

## Best Free Hosting Option

Use Cloudflare Pages.

Why:

- free static website hosting
- fast global delivery
- free preview links
- supports custom domains later
- no server to manage

Cloudflare Pages free limits include 500 builds per month, up to 20,000 files per site, and 100 custom domains per project. See Cloudflare's official Pages limits documentation.

## Simple Launch Path

1. Create a free GitHub account if you do not already have one.
2. Create a new repository called `jerry-meraki-website`.
3. Upload the contents of this `website` folder.
4. Create a free Cloudflare account.
5. Go to Cloudflare Pages.
6. Connect the GitHub repository.
7. Leave build command empty.
8. Set output folder as `/` or root.
9. Deploy.

You will get a free website URL like:

`https://jerry-meraki-website.pages.dev`
